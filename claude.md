# Claude Code Instructions for 247-App

## Project Overview

This project is a mobile application built with React Native and Expo. The goal is to transform the existing Uber UI clone into a comprehensive trades services platform. This platform will connect customers with various tradespeople such as electricians, plumbers, locksmiths, and more.

## Core Principles

- **Modularity:** Write code in a modular and reusable way. Create small, focused components.
- **Clarity:** Write clear, concise, and well-documented code. Use meaningful variable and function names.
- **Testing:** Write unit and integration tests for all new features. Aim for high test coverage.
- **Security:** Follow security best practices to protect user data and prevent vulnerabilities.
- **User Experience:** Prioritize a smooth and intuitive user experience for both customers and tradespeople.

## Development Workflow

1.  **Understand the Task:** Before writing any code, make sure you fully understand the requirements from the PRD.
2.  **Create a Plan:** Break down the task into smaller, manageable steps.
3.  **Write the Code:** Implement the feature, following the project's coding standards.
4.  **Write Tests:** Create unit and integration tests for the new code.
5.  **Update Documentation:** Update the project documentation, including the PRD and any relevant technical documents.
6.  **Commit Changes:** Use the `git-expert` agent to commit your changes with a clear and descriptive commit message.

## Agent-Specific Instructions

-   **`senior-engineer`:** Focus on high-level architecture, complex problem-solving, and code reviews. Ensure that all new features are well-designed and scalable.
-   **`junior-engineer`:** Focus on implementing well-defined tasks, fixing bugs, and writing tests. Ask the `senior-engineer` for guidance when needed.
-   **`git-expert`:** Handle all Git-related operations, including branching, committing, merging, and resolving conflicts. Ensure that the commit history is clean and easy to follow.
-   **`security-analyst`:** Proactively scan the codebase for security vulnerabilities and suggest fixes. Pay close attention to user authentication, data storage, and API communication.
-   **`expo-expert`:** Handle all Expo-specific configurations, updates, and troubleshooting. Ensure that the app is compatible with the latest Expo SDK.
-   **`stripe-expert`:** Implement and maintain the Stripe payment integration. Ensure that all payment transactions are secure and reliable.
-   **`react-native-expert`:** Focus on React Native-specific optimizations, performance improvements, and platform-specific issues.
-   **`documentation-writer`:** Write and update all project documentation, including the PRD, technical specifications, and user guides.
-   **`qa-engineer`:** Create and execute test plans to ensure the quality of the application. Report bugs and work with the engineering team to resolve them.
